      Make the comparison fair before averaging.

      Relative rank · 0–100

      Position within a test

      Each Arena rating becomes a percentile within the four-provider cohort, with ties sharing a midrank. 100 means the highest position in that test, not 100% accuracy.

      Shared tests only

      Same evidence, same weights

      Comparisons use only tests available for every selected model. Missing results never count as zero, and a broader average needs at least two shared tests.

      Small ranking differences are not proof of superiority: when the top two models' confidence intervals overlap, the tool says so.

      From changing sources to one usable dataset.

      One command refreshes the evidence. If anything fails validation, the previous release stays in place.

      collect_arena.py

      Collect

      Reads a revision-pinned Arena snapshot and the OpenRouter model catalog. No API key needed.

      evidence.py

      Validate

      Checks structure, exact model identities, bounds and dates; duplicates are quarantined, not guessed.

      check_update.py

      Review

      A gate compares the new snapshot with the last one and stops for review when new models appear.

      update_data.py

      Publish

      Builds one complete data.js. The site recalculates its leaders from it; no HTML changes.

      Plan features and usage limits are reviewed by hand against official documentation; collection never relabels them as current.
