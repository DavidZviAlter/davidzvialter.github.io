# davidzvialter.github.io

Personal portfolio of David Alter: Computer Science student, Data & AI Analyst.
Live at https://davidzvialter.github.io/

Static HTML, CSS and JavaScript, published by GitHub Pages from the `docs/` folder.
No build step: edit the files in `docs/` and push.

- `docs/index.html`: home page
- `docs/projects/`: one page per project
- `docs/assets/`: shared styles (`site.css`), shared script (`site.js`), page scripts (`js/`), fonts, icons, slides
- `docs/files/`: downloadable project files

The AI tool comparison lives in its own repository and is published at
https://davidzvialter.github.io/ai-tool-comparison/. The home page and
`projects/ai-tool.html` read its live data from there.

The previous Next.js version is kept on the `backup/pre-redesign-2026-11` branch.
